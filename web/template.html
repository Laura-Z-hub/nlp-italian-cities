01 · How we collected it

An API, not web scraping

Script build_corpus.py, which can be re-run at any time to rebuild the same corpus.

STEP 1

MediaWiki API

Plain-text extract of each article. No HTML, no menus. Retries automatically when rate-limited (HTTP 429).

STEP 2

Paragraph filter

Headings and captions are dropped. We keep whole paragraphs only, between 220 and 300 words per text.

STEP 3

First cleaning

IPA and dialect brackets after the city name are removed, e.g. Brescia (afi: /ˈbr(ɛ)ʃːa/ …).

STEP 4

Files + metadata

corpus/text01…20.txt in UTF-8, plus sources.csv with title, URL, date, licence and word count.

03 · displaCy · dependencies

What spaCy gets right, and wrong

Roma è un comune italiano di 2 743 357 abitanti, capoluogo dell'omonima città metropolitana e della regione Lazio …

✓ CORRECTRoma, Lazio, Repubblica Italiana found as entities; dell' → lemma di il.
✗ WRONGcomune = ADJ instead of NOUN; the split number makes abitanti a second nsubj. Our normalisation fixes it.
__SVG1__

Napoli nasce come Partenope, fondata dai Cumani su Pizzofalcone a fine VIII secolo a.C. …, sebbene sporadici reperti suggeriscano una datazione più antica.

✓ CORRECTNapoli, Partenope, Pizzofalcone = LOC; ROOT nasce; fondata → fondare.
✗ WRONGsuggeriscano gets the non-existent lemma suggeriscare; secolo tagged obl:agent.
__SVG2__

Di origine preistorica, l'abitato venne rifondato dai Romani … quando venne occupato dal re germanico Teodorico il Grande.

✓ CORRECTPassive with venire: nsubj:pass + aux:pass, ROOT rifondato; Teodorico il Grande = PER.
✗ WRONGRomani (a people) labelled LOC; Grande becomes a separate subject.

03 · Data quality

Problems we found, and what we did

Fixed

Numbers with spaces

Fixed

Template leftover

Torino: “nella categoria Gamma -.”, a symbol lost in the plain-text export.

Fixed

IPA & dialect brackets

Pronunciation after the city name, removed at collection time.

Clean

No HTML or menus

The API returns plain text, so there are no tags, menus or duplicate lines.

Known bias

Same opening

“X è un comune italiano di N abitanti…” inflates comune, capoluogo.

Discovery

“città” is a stop word

spaCy's Italian stop list contains città (94×). Phase 2: custom stop list.

04 · Application area

How the search engine works

The query goes through the same preprocessing as the corpus, so the two are compared lemma to lemma.

1

Preprocess

Lowercase, word → lemma, stop words removed.
antica → antico

2

TF-IDF

Each of the sentences is a vector. Rare lemmas weigh more.

3

Cosine

Similarity between the query vector and every sentence vector.

4

Rank

The best sentences are shown with the city and a link to the Wikipedia source.

Why this application: one city per document, short factual sentences, and many named entities, so the answers are easy to check.
